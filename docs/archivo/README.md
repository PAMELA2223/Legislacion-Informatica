# Documentación archivada

Los documentos de esta carpeta describen el módulo de **Tutoría
Docente–Estudiante**, que fue retirado de la plataforma junto con el rol
`DOCENTE` (ver resumen técnico de la ampliación de la plataforma).

Se conservan aquí solo como referencia histórica de diseño — no describen
funcionalidad vigente. El código correspondiente (`src/modules/tutoring/`,
modelos `Tutoring*` en la base de datos, rutas `/docente`, `/mi-tutoria`,
`/admin/tutorias`) fue eliminado.
